# Quản trị trung tâm đào tạo

Ứng dụng web nội bộ chạy hoàn toàn trên trình duyệt để quản lý học viên, khóa học, ghi danh và thống kê tổng quan bằng dữ liệu giả.

## Công nghệ

- React 18
- TypeScript strict mode
- Vite
- TailwindCSS
- React Hook Form
- Zod
- Zustand
- React Router

## Cài đặt

```bash
npm install
```

## Chạy môi trường phát triển

```bash
npm run dev
```

## Kiểm tra chất lượng mã

```bash
npm run lint
npm run build
```

## Ghi chú

- Không cần backend.
- Dữ liệu hiện tại là mock/fake data trong mã nguồn.
- Không commit `node_modules`, `dist` hoặc file cache TypeScript.
